# NEON DRIFT

마우스, 터치, 키보드로 빛나는 기체를 움직여 분홍 파편을 피하고 초록 별을 모으는 생존 게임입니다.

## 실행

`index.html`을 브라우저로 열거나 이 폴더에서 아래 명령을 실행하세요.

```bash
python3 -m http.server 8080
```

그다음 `http://localhost:8080`으로 접속합니다.

## 조작

- 마우스/터치 또는 WASD/방향키: 이동
- Space 또는 클릭: 2.6초마다 무적 대시
- P: 일시정지
- 별: 점수와 콤보 증가
- 시작 실드: 첫 충돌을 한 번 막아주는 보호막
- 파편을 아슬아슬하게 피하면 추가 점수
- 분홍 파편: 충돌 시 게임 종료
